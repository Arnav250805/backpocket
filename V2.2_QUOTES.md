## ✨ Features

### Quote Rotation System
- **Changes Every Hour**: New quote appears on the hour (e.g., 3:00 PM, 4:00 PM)
- **Changes on Refresh**: Get a new quote when you reload the page
- **35 Unique Quotes**: Curated collection from successful entrepreneurs
- **Attributed**: Each quote shows the leader's name

### How It Works
The system uses a time-based algorithm that combines:
- **Hour of Day**: 0-23 (midnight to 11 PM)
- **Day of Year**: 1-365
- **Formula**: `(dayOfYear × 24) + hourOfDay`

This ensures:
- ✅ Same quote for the entire hour
- ✅ Different quote next hour
- ✅ Different quotes each day
- ✅ Cycles through all 35 quotes
- ✅ No randomness = consistent during the hour

## 📊 How Rotation Works

### Time-Based Algorithm

```javascript
const now = new Date();
const hourOfDay = now.getHours();        // 0-23
const dayOfYear = getDayOfYear(now);     // 1-365

const seed = (dayOfYear * 24) + hourOfDay;
const index = seed % 35;  // 35 quotes total

return quotes[index];
```

### Example Timeline
```
3:00 PM - 3:59 PM: Quote #15 (same entire hour)
4:00 PM - 4:59 PM: Quote #16 (changes on the hour)
5:00 PM - 5:59 PM: Quote #17 (changes again)
```

### Refresh Behavior
- Refresh at 3:15 PM → Same quote (Quote #15)
- Refresh at 3:45 PM → Same quote (Quote #15)
- Wait until 4:00 PM → New quote (Quote #16)
